# Day 1 Hands-on Lab Manual

## Claude AI and AI-Assisted Development with .NET

This Day 1 content has been split into structured lab modules for easier trainer delivery, participant navigation, and phased execution.

## Audience
Experienced .NET developers, senior developers, technical leads, and solution architects.

## Difficulty
Intermediate

## Day 1 Business Scenario
Enterprise Order Fulfillment Platform

## Day 1 Learning Outcome
Participants learn how to apply AI inside disciplined engineering workflows: understand, design, test, implement, review, validate, and decide.

## Shared Prerequisites
- .NET SDK
- Visual Studio, VS Code, or Rider
- Git
- Claude access
- Claude Code where available
- Anthropic API access for integration labs
- Postman or REST Client
- Terminal or PowerShell
- Internet connectivity

## Verify Environment

```bash
dotnet --version
git --version
```

## Recommended Delivery Sequence
Lab 00 -> Lab 01 -> Lab 02 -> Lab 03 -> Lab 04 -> Lab 05 -> Lab 06

## Notes for Trainers
- Enforce analysis before implementation.
- Require test matrix approval before test generation.
- Require failing regression tests before bug fixes.
- Require code review and validation after AI-generated changes.
